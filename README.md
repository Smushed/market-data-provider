# market-data-provider

## Purpose

This application is the data provider of a larger application that streams data from this server into a frontend.

## AI Use

I am using AI in this project as stack overflow. When I need information I first start with google to find links to articles or stack overflow answers. Then I try and dig through docs. If, after all of that I cannot find an answer I will ask AI but tell it not to write any code, but rather "Answer as an answer in stack overflow would. Do not write code with no explaination. I want to understand the solution". If, after all of that, I still cannot get an answer, I will have the LLM generate the code but explain each step to see the logic I missed.

There are other applications which I manage inside of my Github that I either work with AI to develop or fully vibe code. This is not one of those projects.
